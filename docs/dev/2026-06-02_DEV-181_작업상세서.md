# 2026-DEV-181 작업상세서 — Google 토큰 워머 cron 추가

## 배경
- DEV-180(커밋 f73fdbf78)으로 codex 샌드박스 `network_access=true` 및 turn_timeout 전달을 적용해 06:00 안전브리핑 DNS 차단·600초 타임아웃을 해결함.
- 그러나 17:00 "관장 17:00 내일 일정 리마인드"(job f72dec81be92)에서 oauth2.googleapis.com DNS 실패가 재발.

## 원인
- v1 google-workspace 스킬(`skills/productivity/google-workspace/scripts/gws_bridge.py`, `google_api.py`)은 캐시 토큰(`~/.hermes/google_token.json`)을 읽고, 만료 시 `oauth2.googleapis.com`로 직접 refresh 호출.
- 이 refresh가 codex 샌드박스 내 subprocess(`gws` CLI)에서 일어나면 네트워크가 차단되어 `gws_bridge.py`의 "Token refresh failed (network)" 오류 발생.
- Google access token 수명이 약 1시간이라, cron 실행 시점에 토큰이 만료돼 있으면 캘린더 조회가 실패.

## 해법
- codex 샌드박스 밖에서 토큰을 선제 갱신하는 no-agent cron 워머 도입.
- `~/.hermes/scripts/google_token_warmer.py`: 토큰 expiry를 읽어 만료 20분 전부터 `gws_bridge.refresh_token()`으로 미리 갱신. 유효하면 건너뜀.
- `_run_job_script`(cron/scheduler.py)는 no_agent 잡을 LLM 없이 `sys.executable`(venv 3.11)로 직접 실행 → 샌드박스 네트워크 차단과 무관.
- cron 등록: job_id `cbd9f19c8d1f`, name `google-token-warmer`, schedule `*/30 * * * *`, mode no-agent, profile default.

## 워머 스크립트 전문 (재현용 — repo 밖 `~/.hermes/scripts/`에 위치)
~~~python
import json, sys
from datetime import datetime, timezone, timedelta
from pathlib import Path

SKILL_SCRIPTS = Path.home() / ".hermes/hermes-agent/skills/productivity/google-workspace/scripts"
sys.path.insert(0, str(SKILL_SCRIPTS))

from gws_bridge import get_token_path, refresh_token  # noqa: E402

def main():
    tp = get_token_path()
    if not tp.exists():
        print('WARN: no google_token.json; skip', file=sys.stderr); return 0
    data = json.loads(tp.read_text())
    exp = data.get('expiry','')
    now = datetime.now(timezone.utc)
    if exp:
        exp_dt = datetime.fromisoformat(exp.replace('Z','+00:00'))
        if now < exp_dt - timedelta(minutes=20):
            print(f'token still valid until {exp}; no refresh needed'); return 0
    refresh_token(data)
    fresh = json.loads(tp.read_text())
    print(f'token refreshed; new expiry {fresh.get("expiry")}')
    return 0

if __name__=='__main__':
    sys.exit(main())
~~~
