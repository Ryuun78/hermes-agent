## 2. 원인 (독립 2건)
### 2-1. cron/kanban 샌드박스 네트워크 차단

1. cron/kanban 경로에 외부 API 의존 작업이 있으면 `network_access=true` 필요(전면 비활성 금지).
2. 잡별 타임아웃은 코드가 `run_turn`까지 실제 전달하는지 확인(설정만으로는 600초에 가려짐).
3. cron 변경 검증은 텔레그램이 아니라 cron/kanban 실행 경로에서 직접 확인.
