## 5. 재시작 방식 메모 (중요)
- `hermes gateway restart`는 인자 없으면 **current(default)만** 재시작.
- `--all`은 표기와 달리 default 계열만 정리되는 경우가 있어 전체 교체에 부적합.
- 프로필별 재기동은 launchd 직접 호출이 확실:
  `launchctl kickstart -k gui/$(id -u)/ai.hermes.gateway-<profile>`
